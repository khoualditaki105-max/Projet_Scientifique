# Projet scientifique

## Description
Exemple de gestion de données scientifiques avec Git et GitHub.

## Données
Le fichier donnees.csv contient les températures de quatre villes :
- Annaba : 22
- Alger : 25
- Oran : 27
- Constantine : 20

## Outils utilisés
- Python
- Git
- GitHub

## Objectif
Apprendre à créer, modifier, versionner et partager des données scientifiques.
